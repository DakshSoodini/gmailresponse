**Today I made my first fully independent AI with the help of chatgpt. I decided to make a gmail auto responder 
, that reads a email and makes a response and all I have to do is approve it or edit it or deny it, If I approve it then the 
AI will respond in the same thread without me needing to do anything extra. I also modified it so that the model only checks mails 
from my inbox and ignores spam and promotions.  I first tried to do it using a API from chatgpt-4mini however it was very costly. 
Instead I used a 7 billion parameter model from tiiuae/falcon, I hosted it locally though it was pretty slow it was worth the money saved. Chatgpt coded it and I kept optimising 
it and improved it with the second iteration
